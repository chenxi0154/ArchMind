方法实际目的是更新用户的信息，但是代码却是插入一条新的信息，由于ID相同就会导致主键冲突并导致登录失败。

**正确代码**：
```java
public void updateLoginInfo(Long userId,String ip){  
    User user = new User();  
    user.setId(userId);  
    user.setLastLoginIp(ip);  
    user.setLastLoginTime(LocalDateTime.now());  
    //insert修改成updateById
    userMapper.updateById(user);  
}
```


---

## 区分updateById和update方法

**`userMapper.updateById(user)`：按实体里的主键 `id` 更新。**
```java
user.setId(123L);
userMapper.updateById(user);
```
等价于：
```SQL
UPDATE user
SET last_login_ip = ?, last_login_time = ?
WHERE id = 123;
```

**`userMapper.update(user, wrapper)`：按你提供的条件更新，通常需要第二个参数。**
```java
userMapper.update(
    user,
    new LambdaUpdateWrapper<User>()
        .eq(User::getId, 123L)
);
```
大致等价于：
```SQL
UPDATE user
SET last_login_ip = ?, last_login_time = ?
WHERE id = 123;
```


---


**两种用法都可以是按ID更新**，区别是ID放在哪里：
updateById是将ID放在实体对象中

```java
user.setId(userId);
userMapper.updateById(user);
```

update是把ID写在条件里:
```java

userMapper.update(
    user,
    new LambdaUpdateWrapper<User>()
        .eq(User::getId, userId)
);
```
