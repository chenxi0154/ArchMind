## IP层基本通信
- **同一个局域网下**：两台设备之间IP层基本可以直接通信
- **不同一个局域网下**:两台设备之间存在可用的网络路由，可以跨网络进行IP通信

```
ping <目标IP地址或域名>
```

ping能ping任何的网关也好，服务器IP也可。所以能够逐级排查网络：

```
① ping 自己的网关
       ↓
② ping 局域网其他设备
       ↓
③ ping 公网 IP
       ↓
④ ping 目标服务器
```

## SSH

### SSH解决了什么问题？

```
你的 Windows 电脑
      │
      │ SSH
      ↓
Ubuntu 服务器
192.168.1.100
```

服务器可能放在另一个房间，或者另一栋楼。
不需要给服务器接显示屏，键盘，而是在Windows上：
```
ssh 用户名@服务器IP
```

成功后，终端实际上：

```
Ubuntu服务器的终端
```

此时你就能够在操作你远端的服务器。

### SSH的基本组成

一个SSH连接主要由三个东西：

```
ssh 用户名@IP地址
    │       │
    │       └── 服务器是谁
    └────────── 以什么用户登录
```

例如：
```
ssh root@192.168.1.100
```

表示：
	使用root用户，连接IP为192.168.1.100的服务器


### SSH常见的四种使用方式

**远程登录**：
```
ssh user@server_ip
```


**远程执行命令**：
```
ssh ubuntu@192.168.1.100 "docker ps"
```

**远程传文件**：

**Secure Copy**

例如你的 Windows 有：

`app.jar`

想把它传到 Ubuntu：

`scp app.jar ubuntu@192.168.1.100:/home/ubuntu/`

意思：

`Windows app.jar │ │ SCP ↓ Ubuntu /home/ubuntu/app.jar`

反过来也可以。

## 从自己IP开始

终端查看自己的IP
```Bash
ipconfig
```


1. windows会把不同的网络接口分别列出来：

为什么分**以太网适配器**和**无线局域网适配器**：
- 因为电脑可能同时存在不同的网络接口：
```
	电脑
├── 以太网适配器 Ethernet
│     └── 网线
│
└── 无线局域网适配器 WLAN
      └── Wi-Fi
	
```
本质上都是：让电脑能够来凝结网络的硬件/虚拟接口：
区别在于：
- 以太网适配器    通常对应网线
- 无线局域网适配器   对应Wifi无线连接

所以如果同时插着网线，同时又连着wifi，ipconfig肯两个都有IP

2. 为什么无线局域网下面来由本地连接，WLAN？
   
他们通常代表Windows中存在的不同网络接口/虚拟网络适配器
可能会看到：
```
以太网适配器 Ethernet
    IPv4: 192.168.1.100

无线局域网适配器 WLAN
    IPv4: 192.168.1.101

无线局域网适配器 本地连接* 1
    IPv4: 169.254.x.x

无线局域网适配器 本地连接* 2
    IPv4: 169.254.x.x
```
其中：
WLAN
通常就是真正连接Wifi的无线网卡

**本地连接1/2**
往往是windows创建的虚拟无网线网络接口，例如用Wi-Fi Direct，移动热点，无线投屏等功能

## ZerpTier中的IP

**ZT IP**：虚拟网络中的IP
```
Windows
10.127.43.195
      │
      │ ZeroTier虚拟网络
      ↓
Linux
10.127.43.245
```

所以可以直接：
```
ping 10.127.43.245
```
实际上是测试：Windows → ZeroTier 虚拟网络 → Linux，不需要两台机器处于同一个无论局域网

**Public IP**：设备当前网络的公网通信地址/ZeroTier 看到的网络端点

例如：
```
Windows → 111.55.209.39:15589
Linux   → 218.204.238.91:9993
```

描述的是两台设备在工位中的通信端点。


![[Pasted image 20260831003110.png]]

`10.127.43.245` 确实收到了你的 ICMP 请求，并进行了回复。
