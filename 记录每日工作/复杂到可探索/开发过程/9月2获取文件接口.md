## 一、Controller
```
Controller.listChildren(parentId, projectId) {
  1. 校验 projectId 不为空
  2. 校验 projectId 存在且归属当前用户   
  3. 校验 parentId 属于该 projectId    
     - 利用project_source.fileId来获取根目录       
  4. list = service.listChildren(parentId, projectId)
  5. return Result<List<FileTreeNode>>(list)
}
```

## 二、Service

```
1.校验参数权限归属

2.根据项目Id，确定parentId==null是否为根目录，parentId不为空确认当前parentId是否属于当前项目

3.从数据库中查询某一个项目，某个父目录下的所有子文件，按目录优先，文件其次排序，转换成树节点列表，返回

```


### 原始代码
```java

List<FileEntity> children = fileEntityMapper.selectList(
        new LambdaQueryWrapper<FileEntity>()
                .eq(FileEntity::getProjectId, projectId)
                .eq(FileEntity::getParentId, actualParentId));

children.sort(Comparator
        .comparing((FileEntity f) -> "dir".equals(f.getFileType()) ? 0 : 1)
        .thenComparing(FileEntity::getFileName, Comparator.nullsFirst(String::compareTo)));

return children.stream().map(this::toTreeNode).toList();
```

```
① 查数据库
    ↓
② 排序
    ↓
③ 转换数据并返回
```


#### 第一部分：查询数据库

```java
List<FileEntity> children = fileEntityMapper.selectList( new LambdaQueryWrapper<FileEntity>() .eq(FileEntity::getProjectId, projectId) .eq(FileEntity::getParentId, actualParentId));
```

 翻译成人话

> 查询 file 表中：
> 
> - project_id = projectId
> - parent_id = actualParentId
> 
> 的所有文件，并把查询结果保存到 children 列表中。

1. 定义一个Java泛型集合，变量名为children
2. List< FileEntity > 表示一个LIst，里面只能存放FileEntity类型的数据
3. fileEntityMapper.selectList（）是MyBatis-plus的查询方式，可以理解成selectList(查询条件)
4. 
```java
   List<FileEntity> children = fileEntityMapper.selectList(...);
```
实际上就是：
```
数据库查询
    ↓
得到多条 FileEntity
    ↓
保存到 children
```

5. `new LambdaQueryWrapper<FileEntity>()`
   这是MyBatis-Plus的查询条件构造器：就是构造SQL中的Where条件
	例如：
	
```java
	new LambdaQueryWrapper<FileEntity>()`
```
	相当于准备写：
	
	`WHERE ...`

LambdaQueryWrapper== Lambda查询包装器
作用是组装查询条件，将并将查询内容定义成一个wrapper的变量，由MyBatis-plus的查询方式去进行查询wrapper。

这个查询条件构造器，的作用是找出要匹配的字段，以及这个字段所需要匹配的内容

所以根据上面代码：实际上翻译就是：

我定义了一个列表，这个列表是FileEntity类型的，其他类型的我不存储。这个列表的变量名是children，现在我使用MyBatis的方式查询FileEntity这个实体类对应的数据库中的整个列表，查询的条件是（查询FileEntity实体类中的ProjectId这个字段，的值是projectId参数的值；以及父节点Id是actualParentId参数的值的列表）

### 常用方法翻译

| 方法          | 含义    | 等价 SQL                 |
| ----------- | ----- | ---------------------- |
| eq          | 等于    | `column = 值`           |
| ne          | 不等于   | `column <> 值`          |
| gt          | 大于    | `column > 值`           |
| ge          | 大于等于  | `column >= 值`          |
| lt          | 小于    | `column < 值`           |
| le          | 小于等于  | `column <= 值`          |
| like        | 模糊查询  | `column like '%值%'`    |
| in          | in 范围 | `column in (..., ...)` |
| orderByAsc  | 升序排序  | `order by column asc`  |
| orderByDesc | 降序排序  | `order by column desc` |

> 配套还有：`LambdaUpdateWrapper` → Lambda 更新包装器，用于 update 条件构造。
