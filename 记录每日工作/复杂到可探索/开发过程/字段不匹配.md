组件无法正确显示文件名的核心原因是前后端字段名不匹配，导致组件无法读取后端返回的文件信息：
- **后端返回字段**：`fileName`（文件名）、`fileSize`（文件大小）、`isFolder`（是否为文件夹，1 = 文件夹 / 0 = 文件）、`fileType`（文件类型）
- **组件期望字段**：`name`（文件名）、`size`（文件大小）、`type`（节点类型，'folder'/'file'）、`language`（文件类型）

### 解决方案：
新增地柜转换函数`transformFileTreeData`，将后端字段映射为组件所需格式：
```typescript
// 后端字段 → 组件字段
fileName → name
fileSize → size
isFolder:1 → type:'folder'；isFolder:0 → type:'file'
fileType → language
```

这段代码的作用是数据格式翻译，把后端返回的原始文件树数据，转化成主键el-tree能识别，渲染的标准格式，同时保证字段对应，结构完整

后端数据是树形结构，所以用递归调用自身处理chilren
	如果当前节点有children就在此调用transformFileTreeData吧子节点也转换一遍

props.data可能是两种情况：
	情况1：后端直接返回数组
	情况2：后端返回单个对象
TreeData先把所有的输入都统一成数组的格式：
	后续用`transformFileTreeData`对数组进行处理

触发转换
	把统一后的sourceData穿个transformFileTreeData得到组件能直接用的FileTreeNode

自动数据转换：修改treeData计算属性，自动对父组件传入的后端原始数据进行转换，无需手动处理
