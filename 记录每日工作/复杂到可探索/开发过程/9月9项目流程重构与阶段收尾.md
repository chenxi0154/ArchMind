## 一、今天先定的四个问题 → 结论

| 前端抱怨 | 结论 |
|---|---|
| 新建项目应同时允许上传 | 新建弹窗并入「可选 zip + 立即分析」，提交编排 create→upload→analyze |
| 我的项目纯装饰、无响应 | 「我的项目」做成真实列表页：徽标 + 三点菜单（详情/上传/重新分析/删除），读取现成 `GET /api/project` |
| 领域地图脱离了上传前提 | 中央画布改名「记忆地图」（= 跨项目的个人知识记忆，保留演示数据 + 标注）；真正的「领域地图」放项目详情，近期由已存 overview 驱动 |
| 分析结果从哪来 / 要不要缓存 | 根因是「读概况被设计成再分析一次」。已落库 `project_overview` 却没读接口 → 新增 `GET overview` + analyze 幂等 + 状态列 + Redis 读缓存 |

## 二、后端阶段一（本次工作区改动）

| 文件 | 改动 |
|---|---|
| `ProjectController` | 新增 `DELETE /api/project/{projectId}`（@PathVariable，归属校验 `checkProject` 已下沉进 service） |
| `ProjectService/Impl` | `deleteProject` 事务删 `project_source/file/project_overview/project` 四表 → 再删磁盘 `{upload.base-dir}/{projectId}`（失败仅告警留孤儿）；列表带 `analysisStatus`；新建默认 `NO_SOURCE` |
| `ProjectOverviewService/Impl` | 新增 `projectDatabaseOverview`（读库）；`projectOverview(projectId, force)` 幂等——非 force 且已有结果直接返回；成功后置 `COMPLETED`、失败置 `FAILED` |
| `ProjectAnalysisController` | `GET /{projectId}/overview`（读库）+ `POST analyze?force=` |
| `entity/Project` `dto/ProjectResponse` | 新增 `analysisStatus` 列/字段 |
| `common/constant/ProjectAnalysisStatus` | 状态常量 `NO_SOURCE / PENDING / COMPLETED / FAILED`（新建→NO_SOURCE，上传完成→PENDING，分析成功→COMPLETED/失败→FAILED） |
| `UploadServiceImpl` | 上传扫描成功把项目置 `PENDING` |
| `ProjectOverviewServiceImpl` | Redis 读缓存 `project:overview:{id}`（TTL 30min，存 JSON 字符串）；重分析覆盖写、删除项目时 evict |

**接口契约**
- `DELETE /api/project/{projectId}`：删库表 + 磁盘，幂等（不存在报错不 500）
- `GET /api/project/{projectId}/overview`：纯读库，未分析报「尚未分析」
- `POST /api/project/{projectId}/analyze?force=true|false`：默认 false；**前端「重新分析」必须传 force=true**，否则拿到的是旧结果
- ⚠️ **服务器 MySQL 还没 ALTER 给 project 加 `analysis_status` 列**——未加列前后端一接就报列不存在（SQL 见本会话 / 待办）

## 三、前端阶段二（mock 全流程实测通过）

- **四页面**：工作台（独立首页）/ 记忆地图（原画布改名 + 演示标注）/ 我的项目 / 项目详情，由 `App.page` 状态切换（无路由库）
- 侧栏大上传按钮移除，上传入口收敛到：新建弹窗 / 我的项目行菜单 / 详情页
- **新建项目弹窗**并入「ZIP 可选」+「创建后立即分析」勾选
- **我的项目行**：`analysisStatus` 徽标 + 三点菜单（打开详情 / 上传更新源码 / 重新分析[force] / 删除[confirm]）
- **项目详情**：概况（GET overview）+「领域地图」预览区块（由 overview 的 techStack/modules 驱动，标注为预览），未上传/未分析显示引导
- mock 补齐 DELETE、GET overview、analyze 幂等、upload 清 overview 与状态流转

实测路径：登录 chenxi → 工作台空态 → 我的项目空列表 → 新建（含 zip 字段、未选 zip 时勾选置灰）→ 创建无 zip 项目（详情 NO_SOURCE 引导）→ 三点菜单（重新分析对 NO_SOURCE 正确禁用）→ 删除（行移除 + toast）→ 再造 + 模拟上传 zip（待分析）→ 分析（已分析 + 概况 + 领域地图 4 模块）→ 记忆地图页正常
