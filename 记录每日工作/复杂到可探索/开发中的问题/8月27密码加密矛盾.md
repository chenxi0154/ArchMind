注册保存了明文密码，登录却用BCrypt校验，注册后的账号无法登录
注册时直接用：`setPassword(request.getPassword())`，登录时 `passwordEncoder.matches()` 要求数据库中是 BCrypt 哈希。

`passwordEncoder.matches(A，B)`方法中，A是登录的密码原文，B是加密后的BCrypt。matches方法一定会将第二个参数解析成BCrypt格式。如果存储的也是明文，那么会由于格式不对，直接放回fasle，并记录类似：
```
Encoded password does not look like BCrypt
```


---

所以正确的做法是在注册时，将用户输入的明文密码传给encode（），将返回的BCrypt哈希保存到数据库。

代码修改内容
```java
//先注入PasswordwordEncoder依赖，然后调用passwordEncoder引用变量中的encode方法
    private UserMapper userMapper;  
    private final PasswordEncoder passwordEncoder;  
    @Override  
    @Transactional    public User UserRegister(RegisterRequest request){  
        if (this.existsByUsername(request.getUsername())){  
            throw new BusinessException("用户名已被使用");  
        }  
//        用户不存在啧需要创建用户存放的地方  
        User user = new User();  
//        然后读取参数存到这个实体类中  
        user.setUsername(request.getUsername());  
        user.setPassword(passwordEncoder.encode(request.getPassword()));  
        user.setEmail(request.getEmail());  
        user.setPhone(request.getPhone());  
  
        user.setCreateTime(LocalDateTime.now());  
        user.setUpdateTime(LocalDateTime.now());  
//        上面是将参数内容写入实体类中，然后将真整个实体类插入到userMapper对应的数据表中  
  
        userMapper.insert(user);  
  
        return user;  
    }
```
