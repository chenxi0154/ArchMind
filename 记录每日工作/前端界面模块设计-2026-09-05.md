# ArchMind 前端界面模块设计（2026-09-05）

> 状态：设计稿，暂未开发代码。依据后端 `ArchMind/src/main/java/com/example/archmind` 现有实现整理。

## 0. 产品定位

ArchMind —— 代码项目架构智能分析平台。用户上传代码 zip 包，后端扫描文件树并调用 DeepSeek 生成项目架构解读（技术栈、架构风格、模块划分）。

## 1. 后端接口现状（前端契约）

统一响应包装：`Result{ code, message, data, timestamp }`，认证方式为 JWT（`Authorization` 头），accessToken 2 小时、refreshToken 7 天。

| 模块 | 方法 & 路径 | 请求 | 响应 data |
|---|---|---|---|
| 认证 | POST /api/auth/register | username/password/email/phone | UserInfoResponse |
| 认证 | POST /api/auth/login | username/password | LoginResponse{ userId, username, accessToken, refreshToken, expiresIn } |
| 认证 | POST /api/auth/logout | Header: Authorization | - |
| 认证 | POST /api/auth/refresh | Header: Authorization(refreshToken) | LoginResponse |
| 项目资源 | POST /api/project/{projectId}/upload | multipart file (zip ≤500MB) | UploadResponse{ sourceId, projectId, fileName, fileSize, status, taskId } |
| 项目资源 | GET /api/project/{projectId}/tree?parentId= | parentId 可空（根节点） | List\<FileTreeNode\>{ fileId, fileName, fileType, hasChildren, fileSize, language }（懒加载） |
| 智能分析 | POST /api/project/{projectId}/analyze | - | ProjectOverviewResponse（见下） |

ProjectOverviewResponse 结构：
- projectType / summary / description
- techStack: [{ name, category, version, role }]
- architecture: { style, layers[], description }
- modules: [{ name, responsibility, keyFiles[] }]

## 4. 路由结构

```
/login                 登录 / 注册（Tab 切换）
/                      项目工作台（项目列表 + 新建/上传）
/project/:id           项目详情（三栏布局）
  ?tab=overview        架构概况（默认，AI 分析结果）
  ?tab=files           文件树 + 代码查看
  ?tab=graph           依赖图谱（二期）
```

## 5. 模块拆解

### A. 认证模块（P0，接口已齐）
- 登录/注册卡片，Tab 切换
- Axios 拦截器：注入 accessToken；401 时用 refreshToken 调 /refresh 无感续期，失败跳登录
- 路由守卫

### B. 项目工作台（P1，待后端补 CRUD）
- 项目卡片列表：名称、语言、框架、状态、创建时间
- 新建项目弹窗 + zip 拖拽上传（进度条）
- 空状态引导

### C. 文件树面板（P0，接口已齐）
- 项目详情左栏，懒加载 Tree：展开节点时调 GET /tree?parentId=
- 按 fileType / language 显示图标
- 点击文件 → 右栏代码查看（P2，待文件内容接口）

### D. 架构概况面板（P0，产品核心）
- 摘要卡：projectType + summary + description
- 技术栈表格：name/category/version/role，category 标签着色
- 架构卡：style 徽章 + layers 分层条 + description
- 模块栅格卡：name / responsibility / keyFiles（点击可定位文件树）
- 「开始分析」按钮 + 骨架屏 Loading + 失败重试；建议配合后端异步任务轮询

### E. 全局基础设施（P0）
- Axios 封装：解包 Result.code、统一错误提示、token 刷新
- Vite proxy：/api → localhost:8080
- 环境变量 VITE_API_BASE_URL
